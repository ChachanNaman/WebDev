Synchronous Code : 
it is a type of codes which executes on a same line and doesnt wait in between
ex-> print statements

Asynchronous Code : 
which doesnt executes on the spot , like it doesnt even guarantee that the code will run or not on time
ex : 
function saymyname(){
    console.log("hello naman");
}
setTimeOut(saymyname, 5000); -> defined here 5 seconds but as it Asynchronous it doesnt guarantee of 5 seconds
it could be run after 10 second, 1 minute, doesnt guarantee

Blocking : 
means it will block the Synchronous statements coz of Asynchronous statements
console.log("start");
setTimeOut(saymyname, 5000);
console.log("end"); -> this will be in block state coz of waiting 

To handle this blocking condition EVENT LOOP was introduced 
EVENT LOOP deals with Asynchronous statements
and Synchronous statements runs normally

EVENT LOOP :
console.log("start");
setTimeOut(saymyname, 5000);
console.log("end");
Call Stack ->
Firstly "start" pushed into the stack and popped and printed -> Then setTimeOut func pushed into the stack as 
it is Asynchronous code it is transfered to browser to handle and popped -> then "end" pushed in stack then popped and printed
Browser -> 
It holds the Asynchronous code -> saymyname starts its timer and as timer got finisher it sends saymyname to callback queue to print code inside function
Callback queue -> 
it checks if the stack is empty then pushes the saymyname into stack and print and popped 

Output : 
start
end
Hello naman

Event loop ensures that after the callback step that call stack is empty
